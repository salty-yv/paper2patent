# 论文转中文专利说明书

本地工具把科研论文 PDF 整理成中文专利说明书**草稿**。处理过程分为论文读取、技术概念核对、中文提纲核对、正文生成。Word 草稿之外，还输出每段对应的论文页码与原文摘录，便于发明人复核。

## 启动

双击 [启动工具.cmd](启动工具.cmd)，或在项目目录执行：

```powershell
.\.venv\Scripts\python.exe run.py
```

浏览器访问 <http://127.0.0.1:8765>。首次重新安装环境时执行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 使用

1. 选择论文 PDF。页面会显示页数、原文块数和可能需要检查的页面。
2. 选择兼容 OpenAI 的接口，填写基础地址、模型名和密钥。DeepSeek 官方接口的默认值是 `https://api.deepseek.com` 和 `deepseek-flash`；使用其他服务时更改这两项。
3. 依次点击“提取概念”“生成提纲”“生成 Word 草稿”。正文可按段展开修改，保存后重新核对。
4. 点击“核对原文依据”。工具逐条检查草稿中的技术主张，保存原文引句、论文页码和判断理由；可先筛选“待复核”，再下载逐条核对表。
5. 对引用不足的主张，先点击候选原文块核实，再勾选并加入对应段落，然后重新核对。公式可打开论文页面，记录一致或差异。
6. 下载 Word 草稿、证据对照表和待确认事项。

数学公式在 Word 中导出为可编辑公式；页面预览保留 `$...$` 标记，便于核对模型返回的原式。

模型密钥只保存在当前页面和正在执行的任务内，不写入项目文件。输入论文及每阶段结果保存在 `runs/`，该目录已从版本管理中排除。每次修改概念或提纲，工具会把下游旧结果移至该次运行的 `history/`，随后可以重新生成。

证据核对按原句拆分技术主张，并只使用该段所引的论文原文块。程序会检查模型提供的原文引句是否逐字存在、关键数字是否出现在引句中；漏查、引句对不上或公式无法凭 PDF 提取文字确认时，会标为“待复核”。候选补证从全文概念及表格标题中寻找，但不会自动判定为支持；加入引用后仍需重新核对。“当前引用不足”仅指该段现有引用不能支持主张，不能推断论文其他位置也没有依据。PDF 提取时会清理页边行号，数值表格引用会带上表题和列标题。模型判断及 Codex 页面核对均是辅助审核，最终仍需发明人确认技术事实。调用中断时会按已完成段落续跑；草稿变化后，旧核对结果会失效。

## 当前范围

- 首版处理有可提取文字的 PDF。扫描版会提示需要 OCR。
- 中文章节按技术领域、背景技术、发明内容、附图说明、具体实施方式组织；本地页面当前不开启论文附图复用，因此正文不应生成图号引用。
- 系统会标出缺失信息、数值出处、未覆盖概念等复核项。草稿用于发明人和代理人员继续修改。
- 论文输入目前上限 30 MB、约 14 万个提取字符。超出时会提示先拆分或精简。

方法参考：[FlowPlan-G2P v4](https://arxiv.org/abs/2601.02589)。中文结构依据：[《专利法实施细则》第二十条](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html)。
